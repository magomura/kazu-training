# かずトレ

数の関係を、ゆっくり確かめる基礎算数トレーニング。iPhone Safari向けのLEVEL 1初期試作です。

## 今回の範囲

添付の[初期仕様書 v0.1](docs/spec-v0.1.md)・プロジェクト指示を参照し、2026-10-04の依頼に合わせてLEVEL 1に絞りました。LEVEL 2・3は未実装です。

- 1〜10の大小（大きい数／小さい数）
- 数の順番（連続する3つの数の空欄）
- あといくつで10？
- 10はいくつといくつ？
- 2〜10の分解と合成

## 使い方

「10問 はじめる」→ 数字を入力 →「答える」→ 短い解説 →「次の問題」。時間制限・ランキング・学年表示はありません。紙に丸や式を書きながら使えます。

間違えたときは、数直線・丸の図 → 数える／ひとつ前・次を確かめる補助問題 → 元の問題、の順に進みます。補助問題を2回間違えたら答えと説明を示します。元の問題で再び間違えた場合にも解説して次へ進み、同じ問題で止まり続けない設計です。補助問題は10問に含めません。

前半5問で各タイプを1問ずつ扱います。後半5問は通常70%・復習30%の混合抽選。通常枠でも全タイプを選べるため、復習対象は合計で30%を超えて出る場合があります。復習対象は過去に本問題で誤答したタイプです。頻度の上限・最近の習熟による解除は今後の検討事項です。

## 実行

HTML / CSS / JavaScriptのみ。ビルド・サーバー処理・DB・外部通信は不要です。

PCでの確認用に、リポジトリのフォルダーで次を実行します（Pythonがある場合）。これは静的ファイル配信用であり、アプリのサーバー機能ではありません。

```sh
python3 -m http.server 8765
```

PC: `http://localhost:8765`。同じWi-FiのiPhoneでは `http://PCのLAN内IPアドレス:8765` をSafariで開けます（ファイアウォールの許可が必要な場合があります）。

### 外出先から開くURL

GitHubへのコード保存だけではアプリのWeb公開は完了しません。GitHub Pages等の静的ホスティングを別途設定します。本リポジトリは作成時点で非公開のため、利用プランと公開方針を確認してから設定してください。リポジトリの公開範囲はこの実装では変更していません。

GitHub Pagesを利用できる場合の配信元は `main` ブランチの `/ (root)` です。公開後のSafariでは共有メニューから「ホーム画面に追加」できます。オフライン保証・サービスワーカーは初期試作の範囲外です。

## 保存されるもの

localStorageのキー: `kazu-training:v1`

- 完了した本問題の総数、初回回答での正解数
- 問題タイプ別の完了数、初回正解数、本問題での誤答回数
- 最終学習日、端末の現地日付ごとの完了数

本問題の解説が出た時点で保存します。補助問題の回答、未完了問題、途中のセッション位置は保存しません。再読込後はホームに戻ります。記録は同一端末・同一ブラウザ・同一配信元に限ります。プライベートブラウズやサイトデータの削除では失われることがあります。

保存不可でも練習は続行し、通知を表示します。壊れた履歴や未対応バージョンは勝手に上書きせず、その回はメモリ上だけで練習します。

## 構成

- `index.html` / `styles.css`: モバイル画面
- `engine.js`: 出題、補助問題、復習抽選、履歴形式
- `app.js`: 画面遷移、回答、保存
- `tests/`: 開発用テスト（アプリ実行時には不要）

## 検証

```sh
node --test tests/engine.test.cjs
```

ブラウザテストは開発用のPlaywrightを導入して実行します（テスト自身が一時的な静的配信を起動します）。

```sh
npm install --no-save playwright
npx playwright install chromium
node tests/browser.cjs
```

詳細は[検証記録](docs/verification.md)を参照してください。

## お子さんに試してほしいこと

1回だけ10問を試し、「読みにくい」「入力しづらい」「図で分かった／分からなかった」を観察してください。速さより、指で数える・図を見る・自分の言葉で説明する様子を改善の材料にします。
