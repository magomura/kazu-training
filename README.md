# かずトレ

数の関係を、ゆっくり確かめる基礎算数トレーニング。iPhone Safari向けのLEVEL 1・2試作です。

## 今回の範囲

添付の[初期仕様書 v0.1](docs/spec-v0.1.md)・プロジェクト指示を参照。2026-10-08の使用後のご相談に合わせ、LEVEL 2と「ほしぞらの旅」を追加しました。LEVEL 3は未実装です。

### LEVEL 2（v0.2）

- 10といくつ（11〜19の分解）
- 20までの足し算・引き算。まずは10のまとまりを保って計算
- LEVEL 1の復習2問＋新しい問題8問。基本3タイプを最低1回ずつ出題し、残りは通常70%・苦手30%の抽選
- 最近5回の完了セッションのうち、直近のLEVEL 2で初回正解8/10以上なら、次回は末尾2問を繰り上がり・繰り下がりにする。8/10未満なら基本に戻る。LEVEL 1はいつでも選択可能
- 誤答時は独立した前提問題へ（例：8＋5 → 8にあといくつで10？）。補助と本問題で答えが違っていても、それぞれで判定

### ほしぞらの旅

- 累計10問ごとに6種類のオリジナルSVGの景色を順番に解放。過去の記録も含む。全景色解放後は10問ごとに景色を巡る
- 正解率にかかわらず、やり直して完了した問題も旅が進む。途中終了分も累計に含む
- 1回10問で初回正解8問以上なら、終了画面で流れ星（短いアニメーション、動きを減らす設定では静止画）。回数を保存
- ランキング、制限時間、連続日数のペナルティは設けない
- 保護者向け詳細内に累計正解率と最近5回の結果を表示

### LEVEL 1（いつでも復習）

- 1〜10の大小（大きい数／小さい数）
- 数の順番（連続する3つの数の空欄）
- あといくつで10？
- 10はいくつといくつ？
- 2〜10の分解と合成

## 使い方

「20までの10問 はじめる」または「LEVEL 1で おさらいする」→ 数字を入力 →「答える」→ 短い解説 →「次の問題」。時間制限・ランキング・学年表示はありません。紙に丸や式を書きながら使えます。

間違えたときは、数直線・丸の図 → 数える／ひとつ前・次を確かめる補助問題 → 元の問題、の順に進みます。補助問題を2回間違えたら答えと説明を示します。元の問題で再び間違えた場合にも解説して次へ進み、同じ問題で止まり続けない設計です。補助問題は10問に含めません。

LEVEL 1は前半5問で各タイプを1問ずつ扱います。後半5問は通常70%・復習30%の混合抽選。通常枠でも全タイプを選べるため、復習対象は合計で30%を超えて出る場合があります。復習対象は過去に本問題で誤答したタイプです。頻度の上限・最近の習熟による解除は今後の検討事項です。

## 実行

HTML / CSS / JavaScriptのみ。ビルド・サーバー処理・DB・外部通信は不要です。

PCでの確認用に、リポジトリのフォルダーで次を実行します（Pythonがある場合）。これは静的ファイル配信用であり、アプリのサーバー機能ではありません。

```sh
python3 -m http.server 8765
```

PC: `http://localhost:8765`。同じWi-FiのiPhoneでは `http://PCのLAN内IPアドレス:8765` をSafariで開けます（ファイアウォールの許可が必要な場合があります）。

### 外出先から開くURL

公開URL: https://magomura.github.io/kazu-training/

GitHub Pagesを利用できる場合の配信元は `main` ブランチの `/ (root)` です。公開後のSafariでは共有メニューから「ホーム画面に追加」できます。オフライン保証・サービスワーカーは初期試作の範囲外です。

## 保存されるもの

localStorageのキー: `kazu-training:v1`（既存の保存場所を維持。データ内versionは2へ移行）

- 完了した本問題の総数、初回回答での正解数
- 問題タイプ別の完了数、初回正解数、本問題での誤答回数
- 最終学習日、端末の現地日付ごとの完了数
- 最近5回の10問完了セッション（レベル・初回正解数）、流れ星が出た回数

初期版の記録を読み込んだら、総数・正解数・日別・タイプ別の値を保持して新形式をメモリ上で作ります。次に本問題を完了するまで保存内容は変えません。旧版に10問セッション単位の記録はないため、過去の流れ星回数は推測で追加しません。景色は累計完了数から復元します。

本問題の解説が出た時点で保存します。補助問題の回答、未完了問題、途中のセッション位置は保存しません。再読込後はホームに戻ります。記録は同一端末・同一ブラウザ・同一配信元に限ります。プライベートブラウズやサイトデータの削除では失われることがあります。

保存不可でも練習は続行し、通知を表示します。壊れた履歴や未対応バージョンは勝手に上書きせず、その回はメモリ上だけで練習します。

## 構成

- `index.html` / `styles.css`: モバイル画面
- `engine.js`: 出題、補助問題、復習抽選、履歴形式
- `app.js`: 画面遷移、回答、保存
- `journey.js`: 景色・アルバム・流れ星（外部画像への依存なし）
- `tests/`: 開発用テスト（アプリ実行時には不要）

## 検証

```sh
node --test tests/engine.test.cjs
```

ブラウザテストは開発用のPlaywrightを導入して実行します（テスト自身が一時的な静的配信を起動します）。

```sh
npm install --no-save playwright
npx playwright install chromium
node tests/browser.cjs
```

詳細は[検証記録](docs/verification.md)を参照してください。

## お子さんに試してほしいこと

1回だけ10問を試し、「読みにくい」「入力しづらい」「図で分かった／分からなかった」を観察してください。速さより、指で数える・図を見る・自分の言葉で説明する様子を改善の材料にします。
