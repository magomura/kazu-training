# v0.3：10の橋と星のコレクション（2026-11-11）

## 今回の目的

ほぼ毎日取り組み、迷う場合もあるがほぼ全問正解。6景色が早く集まったという使用後の報告を受け、20以内で数を分ける・合わせる関係を深め、長く少しずつ集める楽しみを追加する。

## 学習

- LEVEL 3：復習2問、繰り上がり・繰り下がり各1問、空欄の足す数・ひく数各1問、残り4問はこの4タイプから抽選。
- 例：8＋7、14−8、8＋□＝13、14−□＝8。20を超える数や九九には広げない。
- 直近の最近5回内のLEVEL 3で初回正解5/10以下なら、空欄問題を一時的に外し、補数・分解と基本計算を増やす。
- 抽選は通常70%＋過去に間違えたタイプ30%。選択範囲は現在のLEVELの出題範囲に限定。
- 10をまたぐ計算で誤答したら、3つの補助問題を1画面ずつ表示。各ステップは2回まで回答してから説明を示す。最後に元の問題へ戻る。
- 8＋7なら「8にあと2で10」「7は2と5」「10＋5」。14−8なら「14は10と4」「8は4と4」「10−4」。
- 元の問題の再回答が正解なら「解き直し正解」。補助問題だけの正解や、答えを表示して終了した場合は含めない。
- 本問題で初めにヒントを見て正解した場合も初回正解。速度や暗記を測る仕組みではない。
- LEVEL 1・2は既存の内容と記録を維持。以前のLEVEL 2に含まれる20までの基本計算はそのまま残す。

## 36種類のコレクション

既存の景色6＋新しい景色18＋珍しい発見6＋記念品6。

### 積み重ねの景色18

更新後の10問完走回数が 1、2、3、5、7、10、14、18、23、28、34、40、47、54、62、70、80、90 回に達したときに順番に解放。正解率を問わず全LEVELで進む。旧6景色は従来どおり累計10問ごと。旧版のセッション回数は完全には保存されていないため、新しい回数を過去の総問題数から推測しない。

### 珍しい発見6

10問完走後に12%で1個を発見し、未取得の中から均等に選ぶ。最初は各種類2%、既に取得したものは重複しない。1日の最初の3完走までが抽選対象（端末の現地日付）。連続14回外れた次の対象抽選＝15回目は必ず1個。スコアやLEVELによって抽選確率は変わらない。

抽選は10問目の本問題を完了する処理で1回だけ行い、結果を同じ保存データに記録。結果画面の再表示・再読み込みでは引き直さない。毎日続ける強制・課金・広告・失う報酬はない。

### 記念品6

|記念品|条件|
|---|---|
|三つ星のコンパス|同じLEVELで3回連続、10問初回全問正解|
|五つ星の王冠|同じLEVELで5回連続、10問初回全問正解|
|十の光のランタン|同じLEVELで10回連続、10問初回全問正解|
|考えなおしの結晶|完走した回に含まれる解き直し正解が累計3問|
|雨上がりの虹|初回正解5問以下の回で1問以上解き直して10問完走、または完走した回の解き直し正解が累計10問|
|10の橋の建築士|LEVEL 3を10回完走|

「不名誉」の表示は使わず、低正答率そのものではなく立て直した行動を記念する。同じ記念品に正答率を下げずに得られる経路も設け、わざと間違える必要をなくす。

連続全問正解はLEVEL別。日を空けても維持。途中終了・途中の再読み込み・誤答では当該LEVELの連続回数を0に戻す。既に取得した記念品や自己最高は消さない。開始を保存し、未完了の開始が再読込時に残っていた場合もリセットする。

## 保存と制約

- キー `kazu-training:v1` を維持、データ内versionは3へ移行。旧v1/v2の総数・日別・タイプ別・最近の結果・流れ星を保持。
- 新しいコレクションの完走回数と連続回数は0から。過去に分からない回数を推測しない。
- 移行済みデータは新しい学習を開始したとき、または本問題の回答後などに保存。旧データの破損・未対応版は上書きしない。
- 保存不可の場合は通知し、その画面内でのみ練習可能。報酬は再読み込み後に保証できない。
- ローカルのみの個人用アプリのため、端末時計・保存データの手編集・複数タブの同時学習への不正対策は対象外。同じ端末・同じブラウザで1画面ずつ使う。
- SVGはオリジナル。外部フォント・画像・サーバー・DBを追加しない。動きを減らす設定に対応。
