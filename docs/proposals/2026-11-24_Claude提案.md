## 1. すぐやること

### E-3 ★★★ iPhone実機での確認（信さんの作業）

**今の状態**：PR #2（減加法・3段階ヒント・声かけ・復習解除）の記録には、「ChatGPTの環境ではブラウザテストを動かせなかった」「iPhone Safariは未確認」と書かれています。Claudeは前回、PCのブラウザで14−8の図を目で確かめましたが、実機ではありません。

**お願いしたいこと**（5分ほど）：公開URLをiPhoneで開き、次を見てください。ホーム画面に追加している場合は、一度アプリを閉じてから開き直してください。

1. LEVEL 3で「ヒントを見る」を3回押すと、「言葉 → 図 → 途中の式」の順に出るか
2. 引き算（例：14−8）でわざと間違えると、「14は10と いくつ」→「10から ひこう」→「のこった数と あわせよう」の3ステップになるか
3. 図で、10の枠の**先頭から**丸が消えているか（ステップ2も本問題も同じ位置か）
4. 22のような20より大きい数も入力できて、「ひき算だね…」と出るか
5. 数字キーボードが出るか、文字が小さすぎないか

1か2が出ないときは、古いファイルが残っている可能性が高いです（次のG-1）。

### G-1 ★★☆（新）更新のたびに、読み込み番号を上げる

**今の作り**：index.html は `engine.js?v=0.3.0` のように番号をつけてファイルを読み込んでいます。ところが、PR #2・#4 で engine.js と app.js を書き換えたあとも、番号は 0.3.0 のままです（index.html は v0.3 から変わっていない）。

**困ること**：Safariが古い engine.js を覚えたまま、新しい app.js だけを読むと、新しく足した「ヒントの3段階」の仕組みが見つからず、ヒントのボタンが動かなくなります。GitHub Pagesは10分でファイルを読み直す設定なので、たいていは自然に直りますが、ホーム画面に追加したアプリは古いまま残りやすいです。なお公開中のサイトのファイル自体は最新になっていることを確認しました。

**提案**：
- 今回、index.html の `?v=0.3.0`（5か所）を `?v=0.3.2` などに上げる
- 今後、js・css を変えたときは**必ず**この番号も上げる、と README の「実行」か「検証」の節に1行書いておく
- ヘッダーの表示（`v0.3 · 星空の旅 第2章`）も同じ番号にそろえると、iPhoneの画面で「新しい版か」を見分けられる

**直す場所**：index.html だけ。プログラムの動きは変わりません。

## 2. 採用をおすすめするもの

### A-3 ★★☆ ヒントなしで正解したことを記録する

**今の作り**：ヒントの段階（`hintStage`）は画面の中だけで数えていて、保存していません。ヒントを3段階見て正解しても、初回正解として記録されます（仕様どおり）。

**提案**：初回正解の数え方は変えずに、問題タイプごとに「ヒントなしで初回正解」の数を別に足す。おうちの方向けの「学習の記録」に、タイプ別のヒントなし正解の割合を出す。子どもの画面には出さない。

**今のコードとの合わせ方**：A-2で入った `firstCorrectStreak` と同じく、タイプ別の任意項目（例：`noHintCorrect`）として足せば、保存キー（記録の保存場所の名前）・version 3（保存データの形の番号）・旧記録の読み込みを壊さずにすみます。旧記録は0から数えます（過去の分は推測しない）。

**この先の使い道**：D-1の「できるようになった」の判定に使えます。

### C-3 ★★☆ 5のまとまりが見えるすき間

**今の作り**：10の枠は5列×2段で、丸の間はどこも同じ9pxです。8は「上の段5個＋下の段3個」に並ぶので、5のまとまりは段の形で見えています。

**提案**：段と段の間（上の5個と下の5個の間）だけ、少し広くあける。styles.css の `.ten-frame` で、縦のすき間を横より大きくするだけです（例：横9px・縦16px）。色・丸の形・枠の線は変えません。

**ねらい**：7や8を「5といくつ」で、数えずにぱっと見て分かるようにする。

### H-1 ★☆☆（新）おうちの方への説明に、教え方を書いておく

**今の作り**：ホームの「おうちの方へ・学習の記録」には、レベルの説明・景色・コレクションの条件は書いてありますが、**減加法で教えていること**と、**ヒントが3段階であること**は書かれていません。

**提案**：次の2行を足す。
- 「10をまたぐ引き算は、学校と同じ減加法で考えます（14−8 → 10から8をひいて2、2と4で6）。」
- 「ヒントは『言葉 → 図 → 途中の式』の順に1つずつ出ます。まず言葉だけで考えるよう声をかけてください。」

**ねらい**：信さん以外の家族が横で見るときにも、同じ教え方・同じ声かけになるようにする。

## 4. 保留・見送り・要相談

### C-2 ★☆☆ 分けた数のラベル（保留）

8＋7の図で、1枚目の枠のオレンジ2個に「2」、2枚目の5個に「5」と数字を添える案。B-1の3段階目（途中の式）で「8＋2＝10、7のこりは5」が文字で見えるようになったので、効果は前より小さくなりました。iPhoneで使う様子を見て、「図を見ても分け方が分からない」様子があれば採用、で十分です。

### D-2 ★☆☆ おうちの人に説明するミッション（保留）

アプリに入れなくても、終わったあとに「今日の1問、どうやって解いた？」と聞くだけで同じ効果があります。家での声かけで足りていれば不要です。

### E-1 2人で同じ端末を使う場合（使い方しだい）

記録・景色は端末とブラウザごとに1人分です。きょうだいで同じiPhoneを使っていなければ、何もしなくて大丈夫です。使う場合は「だれがやる？」の選択と、記録を分ける仕組みが必要になります（保存の形が変わるので、そのときにあらためて提案します）。

### B-2 ヒントの言葉を問題ごとに具体的に（見送り）

PR #2 で、ヒントの3段階目（途中の式）は問題の数字入りになりました（例：「8 ＋ 2 ＝ 10。7の のこりは5。」）。1段階目に数字まで入れると、考える前に答えの道すじが見えてしまうため、1段階目は今の「10をつくれないかな？」のような言葉のままがよいと考えます。

### A-4 次の段階の問題（**要相談**）

3つの数の計算（7＋3＋4）、短い文章題、同じ答えになる式さがし（13 ＝ 8＋□ ＝ 9＋□）など。どれも20以内・九九なしの範囲ですが、**問題の傾向が変わる**ので要相談です。LEVEL 3で「ヒントなしでもほぼ全問正解」が続くようになってから（A-3の記録で分かります）考えるのがおすすめです。
