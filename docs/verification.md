## 通過した検証

- Node.js 24: `node --test tests/engine.test.cjs`、4件成功。
- 5タイプ × 2,000問＝10,000問の答え・出題範囲・補助問題との整合。
- 20,000回の抽選で、復習対象1種類が理論値44%（通常70%×1/5＋復習30%）付近に出ること。
- 初回正解数、完了数、タイプ別誤答数、日付別の履歴、不正な保存データの検出。
- Chromium 134 / Playwright 1.51.1で `tests/browser.cjs` 成功。
- 10問を通して回答し、終了画面になること。前半5問が全タイプを含むこと。
- 初回不正解 → 補助問題 → 補助問題で2回不正解 → 答えと説明 → 元の問題 → 正解。
- 元の問題で再び間違えても、解説から次に進めること。
- 補助問題を総問題数・10問ミッションに重複計上しないこと。
- 空入力を拒否し、誤答として数えないこと。
- 再読込後に履歴を復元すること。
- 320 / 390 / 430pxの画面幅で5タイプの補助画面が横にはみ出さないこと。回答ボタン高さ48px以上。
- 保存データ破損時に通知し、既存データを上書きしないこと。
- localStorageへの書込を拒否された場合にも練習が続けられること。
- ブラウザのJavaScriptエラーなし。
- 日本語フォントを用意した検証環境で、390px幅のホーム・補助画面のスクリーンショットを目視確認。
